A model, not a stack of cutouts.

This first procedural model has jointed limbs, a three-dimensional mouth cavity, teeth, moving eyelids and removable equipment. It explores DEX’s proportions; it is not a finished sculpt or a replacement for the game renderer.

A production version can use a sculpted mesh, a painted UV skin and a deforming skeleton. This prototype uses articulated parts and procedural deformation, not a finished skinned character rig. Three.js is bundled locally under its MIT licence.
